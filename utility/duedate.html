The published deadlines.json differs from this browser's list.

This page has two tabs, each an independent list with its own browser storage and its own companion file. Proposal Due Dates reads proposals.json under key deadlinePlanner.proposals.v1. Conference Submissions reads conferences.json under key deadlinePlanner.conferences.v1. Editing a tab changes only this browser until you publish. To publish: pick the tab, press Export JSON, commit the downloaded file next to this page in your repository, then open the GitHub Pages URL. The companion files load over http(s) such as GitHub Pages, not from a bare file:// open. Export .db builds a real SQLite file. Fonts load from Google when online and fall back to system faces offline.
