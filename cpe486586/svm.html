What to watch

Open One outlier with the linear kernel. At C = 1000 the margin shrinks to keep the outlier on its own side. Slide C down to 1 and the margin widens, and the outlier becomes a slack point with ξi > 1.

Press Restart and step. An SMO step changes exactly two multipliers, because Σαiyi = 0 pins a lone multiplier in place.

On Two rings, no value of C rescues the linear kernel. Switch to RBF, or to polynomial with p = 2.

The method in five lines

1.   minw, b, ξ  ½‖w‖2 + C Σi ξi   s.t.   yi(w⊤xi + b) ≥ 1 − ξi,   ξi ≥ 0
The primal. Maximizing the margin d = 2/‖w‖ is the same as minimizing ½‖w‖2. The slack ξi lets a point sit inside the margin, at price C.
2.   maxα  Σi αi − ½ ΣiΣj αiαj yiyj κ(xi, xj)   s.t.   Σi αiyi = 0,   0 ≤ αi ≤ C
The dual, from setting ∂L/∂w, ∂L/∂b and ∂L/∂ξi to zero. The data enter only through κ.
3.   pick the pair (i, j) that violates the KKT conditions most, and solve for αi, αj exactly
That is one SMO step. The pair moves along the line yiαi + yjαj = const, clipped to the box [0, C]2.
4.   w = Σi αiyiΦ(xi),   b = ys − Σi αiyiκ(xi, xs) for 0 < αs < C
This page averages b over the support vectors on the margin. With none on the margin, it takes the middle of the interval the KKT conditions allow.
5.   ŷ = sign( Σi∈S αiyiκ(xi, x) + b )
Only the support vectors S, the points with αi > 0, enter the prediction.

Why it works

For x, z in ℝ2, Φ(x)⊤Φ(z) = x12z12 + 2x1x2z1z2 + x22z22 = (x⊤z)2 = κ(x, z).

The plane is found by a linear SVM on the lifted points. Training the same SVM in the plane with the polynomial kernel κ(x, z) = (x⊤z)2 gives the same boundary without ever computing Φ.

Two rings separate along x12 + x22, so the plane stands upright. XOR separates on the sign of x1x2, so the plane lies flat at √2 x1x2 = 0.

In scikit-learn

The plane on this tab matches SVC(kernel='poly', degree=2, gamma=1, coef0=0, C=100) trained on the original two columns. That kernel is (γx⊤z + c)p with γ = 1, c = 0 and p = 2.

With c > 0 the feature map gains the linear terms √(2c) x1, √(2c) x2 and a constant, so Φ becomes 6-dimensional. The kernel still costs one 2-D dot product.

The RBF kernel's feature space is infinite-dimensional, which is why the training tab never forms Φ at all.
